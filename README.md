# IPA Reloader

IPAのCBT申込サイトで504エラーが出た際に、自動でリロードするChrome / Edge用の拡張機能です。

## 作った背景

CBTの申込開始直後はアクセスが集中し、504が頻発します。それを対処するために作成しました。
~~手動でリロードするのが、めんどいんですよ、本当に。~~

## 主な機能

- **タイムアウトの自動検知**: 画面の「timeout」などの文字列を検知してカウントダウンを開始します。
- **POSTフォームの自動再送**: 送信ボタンを押した際に入力内容を一時保存し、504画面になったら同じ内容でPOST再送信します。
- **GETアクセスの自動リロード**: 通常の画面閲覧時に504が出た場合は、指定秒数後にページを再読み込みします。
- **カウントダウン表示**: 画面上部にバナーが表示され、再送までの秒数をカウントダウンします。手動での「直ちに再送」や「一時停止」も可能です。
- **設定ポップアップ**: ツールバーのアイコンから、自動再送のオン/オフ、待機秒数、最大試行回数の設定ができます。

## 制限事項

- 画面に504関連のメッセージが出ている場合のみ動作します。メンテナンス画面やセッション切れの画面などには反応しません。
- 決済や最終確定の画面でも再送が走るため、二重決済などの懸念がある画面では右上のバナーから「一時停止」するか、ポップアップで待機時間を長めに設定してください。

## インストール

1. ChromeまたはEdgeのアドレスバーに以下を入力して開きます。
   - Chrome: `chrome://extensions/`
   - Edge: `edge://extensions/`
2. 画面の「デベロッパーモード」をオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」（Edgeは「展開して読み込み」）をクリックし、このフォルダを選択します。
