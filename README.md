# IPA Reloader

IPAのCBT申込サイト（`itee-r8cbt.ipa.go.jp`）で発生する504タイムアウトを検知し、自動で再送信を行うブラウザ拡張機能です。Google ChromeおよびMicrosoft Edge（Manifest V3）に対応しています。

---

## 1. 通信解析の知見: 30秒制限のタイムアウトは再送で復帰可能

申込サイトの通信ログ（HARファイル 296件）を解析したところ、混雑時の遮断には以下の特徴がありました。

- **30秒の強制タイムアウト**:
  Google Front End（サーバー手前のロードバランサ）の応答制限時間は約30秒（実測30,017ms〜30,021ms）です。混雑で処理が30秒を超えると、本文に `upstream request timeout` または `stream timeout` を含むテキスト形式の 504 Gateway Timeout が返されます。
- **正常通信との境界**:
  アクセス集中時でも処理が通ったリクエスト（200 OK）の所要時間は19秒〜28.9秒でした。サーバーが完全にダウンしているのではなく、処理待ちがわずかに30秒を超えたリクエストだけが弾かれています。
- **同一フォームの再送信による復帰**:
  フォーム送信（POST）で504エラーとなった直後、同一内容を再度送信して正常に登録完了（200 OK）できている実例が記録されています。したがって、直前の送信内容を保持し、504検知時に自動で再送信するアプローチが有効です。

---

## 2. 機能一覧: フォーム保護と自動再送の仕組み

- **タイムアウト自動検知**:
  画面内のエラー文言（`upstream request timeout`、`stream timeout`、`504 Gateway Timeout`等）を検知します。接続中断などのブラウザレベルのエラーもバックグラウンドで監視します。
- **POSTフォーム内容の自動再送信**:
  送信ボタンを押した際に入力内容をブラウザの一時ストレージへ保存します。504エラー画面を受信した場合は、保存したデータからフォームを再構築して自動送信します。
- **GETアクセスの自動再読込**:
  画面閲覧時のタイムアウトでは、設定した待機時間後にページ全体を再読込します。
- **カウントダウン通知バー**:
  混雑検知時に画面上部へ通知バーを表示し、再送までの秒数をカウントダウンします。「直ちに再送」「一時停止」ボタンによる手動制御も可能です。
- **設定ポップアップ**:
  ツールバーのアイコンから動作設定を変更できます。自動再送のオン・オフ、待機秒数（1〜10秒、推奨3〜5秒）、上限試行回数の変更と、直近の通信ログ確認が可能です。

## 3. インストール手順

1. ブラウザのアドレスバーに拡張機能の管理画面URLを入力します。
   - **Chrome**: `chrome://extensions/`
   - **Edge**: `edge://extensions/`
2. 画面内の **「デベロッパーモード」** をオンにします。
3. **「パッケージ化されていない拡張機能を読み込む」**（Edgeは「展開して読み込み」）を選択します。
4. 本フォルダ（拡張機能のルートフォルダ）を選択します。
5. ツールバーに「IPA Reloader」が追加されたら完了です。
